# دليل تشغيل FootballVideoStudio

كل الأوامر في هذا الدليل جُرِّبت على هذا الجهاز. شغّلها من مجلد المشروع:
`C:\Users\User\Desktop\FootballVideoStudio`

## ١. أنواع الفيديو المتاحة

| النوع | الاسم في الإعدادات | المقاس | حلقة تجريبية |
|---|---|---|---|
| خمّن اللاعب من انتقالاته | `transfer-history` | عمودي ‎1080×1920 | `episodes/modric` |
| خمّن من الجنسية والنادي والرقم والمركز | `guess-attributes` | عمودي | `episodes/salah-attributes` |
| من سجّل الهدف؟ | `who-scored` | عمودي | `episodes/who-scored-maradona-1986` |
| قصص اللاعبين والوثائقيات | `story` | أفقي ‎1920×1080 | `mbappe-story`، `bale-story`، `maradona-story`، `ucl-2019` |
| تاريخ الأندية | `club-history` | أفقي | `episodes/milan-berlusconi` |
| تحليل ومقارنات | `analysis` | أفقي | `episodes/pep-city-analysis` |

كل العيّنات الحالية **معاينات**، لأن صوتها آلي (SILMA) ولم توافق عليه بعد. الحلقات الطويلة (١٥–٢٠ دقيقة) مخططة فقط، في `episodes/*/narration/FULL_OUTLINE.md`.

## ٢. كيف تطلب حلقة جديدة

اكتب لـ Claude في هذا المجلد طلبًا واضحًا، مثل:

> حلقة جديدة من نوع guess-attributes عن لاعب X، حسب موسم 2025/26، بأربع معلومات.

> حلقة story عن نادي/لاعب Y، معاينة دقيقتين، ثم الخطة الكاملة ١٥ دقيقة.

سيقوم Claude بما يلي:
- يتحقق من الحقائق من مصدرين، ويكتبها في `sources.md`.
- ينسخ مجلد حلقة مشابهة إلى `episodes/<الاسم>`، ويملأ `episode.json`: النوع، والموضوع، والمدة المستهدفة، والمقاس، واللغة، وإعدادات الصوت، والفصول والمشاهد.
- يبني المشاهد ويصيّرها ويتحقق منها.

تذكّر:
- في نوع «المعلومات» يجب ذكر الموسم المرجعي (`asOf`) لأن المعلومات تتغيّر.
- في «من سجّل الهدف» لا تُستخدم لقطات المباريات (محمية بحقوق النشر). نستخدم إعادة تمثيل تكتيكية مكتوب عليها ذلك.
- في «التحليل» يجب كتابة معايير المقارنة (`criteria`) وعرضها.

## ٤. التعليق الصوتي

### الطريقة (أ): صوت SILMA المحلي (آلي ومجاني)
```bash
node studio/narration.mjs tts episodes/modric
```
- يولّد صوتًا عربيًا لكل سطر في `audio/tts/`.
- يكتب تقريرًا في `audio/tts_report.md` يقارن نص السطر بما سمعه برنامج التعرّف على الكلام.
- **استمع قبل الموافقة.** Claude لا يسمع الصوت؛ التقرير دليل تقني فقط.
- عيّنات للاستماع: `docs/voice-audition/` (اقرأ README.md هناك).
- **صوت المرجع** الحالي مرفق مع SILMA ومصدره غير موثّق، فهو للتجربة فقط. للنشر: سجّل ٨ ثوانٍ بصوتك واقرأ فيها جملة واحدة، ثم ضع في `episode.json`:
  `"voice": { "ref": "narration/my_voice.wav", "refText": "نص الجملة التي قرأتها" }`
- **لتصحيح نطق اسم:** أضفه إلى `templates/pronunciation.json`، أو شكّل الكلمة في النص (حركتان على الأقل).

### الطريقة (ب): Clipchamp (يدوية)
1. شغّل:
   ```bash
   node studio/narration.mjs script episodes/modric
   ```
   يكتب النص مع أسماء الملفات في `episodes/modric/narration/SCRIPT.md`.
2. في Clipchamp: **إنشاء فيديو** ← **التسجيل والإنشاء** ← **تحويل النص إلى كلام**.
   - اختر اللغة **العربية**، ثم اختر صوتًا.
   - الصق السطر، واضغط **معاينة** للاستماع إلى النطق (عدّل التشكيل إن لزم).
   - اترك السرعة عادية.
   - (أسماء القوائم قد تختلف قليلًا حسب نسخة Clipchamp عندك.)
3. صدّر الصوت، وسمِّ الملف كما في SCRIPT.md، مثل `03_c2.mp3`. أو صدّر ملفًا لكل فصل `CH_ch2.mp3`، أو ملفًا واحدًا للتعليق كله. ضعه في:
   `episodes/<slug>/narration/incoming/`
4. شغّل:
   ```bash
   node studio/narration.mjs import episodes/modric
   ```
   الاستيراد:
   - يستخرج الصوت من mp4 إن لزم.
   - يقصّ الصمت ويضبط مستوى الصوت.
   - يقسّم الملف الكامل عند حدود الجمل، بعد مطابقتها مع النص عبر التعرّف على الكلام (وليس بالصمت فقط).
   - يكتب تقريرًا في `audio/import_report.md`. راجع الأسطر المعلَّمة.

عند التصيير تُستخدم الأصوات بهذا الترتيب: Clipchamp في `audio/final`، ثم SILMA في `audio/tts`، ثم مسودة eSpeak، ثم الصمت. **لا يُسرَّع الكلام أبدًا؛ المشهد يطول ليناسبه.**

## ٥. البناء والتصيير والتحقق
```bash
node studio/build.mjs episodes/modric
```
```bash
node studio/textcheck.mjs episodes/modric
```
```bash
node studio/render.mjs episodes/modric
```
```bash
node studio/verify.mjs episodes/modric
```
- **textcheck:** يفحص النص العربي في كل مشهد: الحروف كاملة، ولا خروج عن الإطار، ولا تداخل، ولا رموز خاطئة.
- **verify:** يفحص المقاس والمدة والصوت وتزامن التعليق والعدّ التنازلي، ويقارن الإطارات من الفيديو النهائي بمصدرها (بعد الحركة وفي منتصفها).
- **اختياري:** OCR عربي من ويندوز كدليل مساند:
  ```bash
  node studio/ocrcheck.mjs episodes/modric
  ```

## ٨. ما يحتاج منك
1. **الصوت:** الاستماع إلى عيّنات SILMA والموافقة عليها أو رفضها، وتسجيل صوت مرجعي إن أردت النشر بها. أو تصدير التعليق من Clipchamp يدويًا.
2. **الحلقات الطويلة:** الموافقة على عيّنة القصة (دقيقتان) قبل إنتاج أي حلقة بطول ١٥–٢٠ دقيقة.
3. **الحقوق:** مراجعة تراخيص الصور قبل النشر، وتأكيد ثانٍ لبعض الحقائق المعلَّمة في ملفات `sources.md`.

## ٩. بوت ديسكورد (جديد)

**التجهيز مرة واحدة** (التفاصيل في `docs/SETUP_WINDOWS.md`):
1. **أعِد إنشاء توكن البوت** من Discord Developer Portal ← Bot ← Reset Token، لأن التوكن القديم كان مكتوبًا داخل `bot.py`.
2. انسخ `.env.example` إلى `.env`، وضع فيه التوكن الجديد ورقم حسابك في `ALLOWED_USER_IDS`.
3. ثبّت المتطلبات وشغّل الاختبارات:
   ```powershell
   py -m venv .venv
   ```
   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
   ```powershell
   .\.venv\Scripts\python.exe -m pytest -q
   ```
4. شغّل البوت:
   ```powershell
   .\.venv\Scripts\python.exe -m bot.main
   ```

**الأوامر:**
| الأمر | ماذا يفعل |
|---|---|
| `/guess_player` | يبحث عن اللاعب في ويكي بيانات وويكيبيديا، ويبني اختبار الانتقالات أو المعلومات تلقائيًا |
| `/player_story` | يبني هيكل فيلم وثائقي من معلومات موثّقة، وحزمة بحث تكتب منها الفصول |
| `/goal_quiz` و `/create_video` | يصنعان الفيديو من حلقة جاهزة |
| `/preview` | صور المشاهد فقط (سريع) |
| `/job_status` و `/cancel_job` و `/retry_job` | متابعة المهام وإلغاؤها وإعادتها |

**طريقة العمل:**
- قبل أي تصيير، يعرض البوت **خطة** فيها كل معلومة وحالتها: ✅ موثّقة من مصدرين، ⚠️ مصدر واحد، ❌ تعارض بين المصدرين. زر الموافقة معطّل عند وجود تعارض.
- إذا كان الاسم يطابق أكثر من لاعب، يسألك البوت عن اللاعب المقصود ولا يخمّن.
- يمكنك تعديل الخطة يدويًا في `episodes/<slug>/episode.json` قبل الموافقة.
- إذا كان الفيديو أكبر من حد ديسكورد (١٠ ميغابايت عادةً)، يرسل البوت نسخة معاينة أصغر، ويبقى الفيديو الكامل في `out\`.

**بدون ديسكورد:** الخطوات نفسها من سطر الأوامر:
```powershell
.\.venv\Scripts\python.exe -m bot.cli research "Luka Modric" --quiz transfers
```
```powershell
.\.venv\Scripts\python.exe -m bot.cli render luka-modric-transfers
```

**الترجمة المتزامنة كلمة بكلمة:** تعمل تلقائيًا في الفيديوهات الأفقية، وتُحفظ معها ملفات `.srt` ليوتيوب. تُعطَّل في حلقة معيّنة بإضافة `"captions": {"enabled": false}`.

**الموسيقى:** أضف إلى `episode.json`:
`"music": {"file": "assets/music/x.mp3", "license": "مصدرها وإذن الاستخدام"}`
تنخفض الموسيقى تلقائيًا عند الكلام.

**لتتعلّم النظام وتعدّله بنفسك:** اقرأ `docs/HOW_IT_WORKS.md` و `docs/TUTORIAL_TEMPLATES.md`.
